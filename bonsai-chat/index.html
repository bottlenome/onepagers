三値(1.58bit)/1bit LLM の Bonsai ファミリーを自作WebGPUカーネルで低ビットのままブラウザ実行
未読込
技術メモ: なぜWebLLMではなく自作エンジンか

Bonsai ファミリーは線形層の重みが三値 {-1, 0, +1}（1.58bit）またはバイナリ（1bit）で学習された低ビットLLM。 WebLLM/MLC の prebuilt には三値/1bit 量子化が存在せず、bf16 展開でコンパイルすると低ビットの利点（メモリ・帯域）が消える。 本ページは PrismML が llama.cpp をフォークして低ビットカーネルを整備したのに倣い、WebGPU の WGSL カーネルを自作して低ビットのまま実行する。

  • Bonsai 0.5B (deepgrove): bf16 の潜在重みを取得しブラウザ内で clamp(-1,1).round() → 2bit/重み にパック（16重み/u32）＋出力チャネル毎スケール
  • Bonsai 1.7B/4B/8B (PrismML): Qwen3 アーキテクチャの MLX 量子化形式（group_size=128 の affine 量子化、1bit/2bit パック済み）をそのまま GPU に載せ、w = scale·q + bias をカーネル内でデコードしながら積和
  • 計算は全て f32。fp16 格納部（スケール・バイアス・norm・KVキャッシュ等）は u32 パック＋unpack2x16float でデコードし、shader-f16 拡張に依存しない
  • Qwen3 系は QK-norm・YaRN RoPE・tied embeddings・<think>思考モードに対応
  • パック済み重みは OPFS にキャッシュされ、2回目以降はダウンロード不要
