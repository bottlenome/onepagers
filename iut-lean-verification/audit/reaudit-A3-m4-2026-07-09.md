## 各項判定（精読）

### 1. choice-free の裏取り（本監査の最重点・射影全射性で DC を隠していないか）

**合格（本物）。** 疑わしい 3 点を個別に潰した:

- **zpu の Hensel 逆元**: `zpuInv : Nat → Nat → Nat` は再帰**関数**（基底 `a % 3`、段
  `b + t·3^{m+1}`・t は `ctr_tex` の閉じた式・項レベル ite）。`zpuInv_spec` は帰納で
  `¬3∣zpuInv m a ∧ a·zpuInv m a ≡ 1 (mod 3^{m+1})` を証明。∃ からの witness 取り出しでは
  なく、値が閉じた式。axiom = [propext, Quot.sound]。
- **zps の射影全射性 `zps_proj_surjective`**: 単数側逆系（(ℤ/3^{n+1})^×・遷移射は
  単発 `% 3^{i+1}`）で、レベル n の任意元 a に対し witness 族 `zpsWitnessFam a m = a % 3^{m+1}`
  （閉じた式）を与え、`zpsWitnessFam_compat`（`Nat.mod_mod_of_dvd`）で整合、
  `limitProj` の n 成分 = a を `Nat.mod_eq_of_lt` で確定。**一般 Mittag-Leffler の可算従属選択を
  一切使わない**——単数側の切断が truncation で閉じているため。これは本塔（可換・円分）
  固有の性質で、ヘッダ限定 (ii) が正しくその旨を明記している（一般 ML は非形式化）。
- **cps の射影全射性 `cps_proj_surjective`**: `obtain ⟨u,hu⟩ := zps_proj_surjective n (χ_n τ)`
  は**目標が Prop（∃ s …）である Exists.elim** であり choice を要さない。しかも被消去の ∃ 自体が
  閉じた witness（zpsWitnessFam）で構成的。原像 `cliFrom.map u` は cli（データ）の逆極限同型の
  像＝閉じた式。axiom = [propext, Quot.sound] が最終確認。**DC/ML の隠蔽なし。**

### 2. 指標同型 cci が本物か

**合格。** `cciIsoData ℓ hℓ` は**本物の双方向群同型**:
- `cciToUnits`（χ_ℓ: Gal → (ℤ/3^ℓ)^×）は `Hom`（map_mul = `cci_charG_mul` を Subtype.ext）。
- `cciFromUnits`（σ_a: (ℤ/3^ℓ)^× → Gal）は `Hom`（map_mul は `cae_aut_ext` の生成元一点比較で証明）。
- `left_inv` = `cci_left_inv`（σ_{χσ}=σ・`cae_aut_ext`）、`right_inv` = `cci_right_inv`
  （char(σ_a)=a・`cci_charG_csaAut`）。両方**証明済み**。
- 単射 = `cae_aut_ext`（元は指標で決まる・M2 済み）、全射 = `csaAut`（実体自己同型 σ_a・
  逆元 witness は `zpuInvL`・choice-free）が**実使用**（cciFromUnits の本体）。
- **`cci_charG_mul`（M4a 新規数学）は fudge でない**: (σ·τ)(ζ)=σ(ζ^b)=ζ^{ab}
  （`ctr_charG_spec`＋`ctr_sigma_powG`）と (σ·τ)(ζ)=ζ^{char(σ·τ)} を突き合わせ、
  両指数 < 3^ℓ で `cci_indexG`（μ の位数ちょうど 3^ℓ ＝ `ctm_powers_distinct` を実使用）
  により char(σ·τ)=a·b mod 3^ℓ を確定。指標積公式の本物の証明。

### 3. 極限同型 cli が本物か（最重要）

**合格。** `cliIsoData` は M3 の実 profinite `ctlProfinite`（= `profPi1Limit ctlTower`・
実 2 段以上非自明円分塔の逆極限）と `zpsLimit`（= `limitGrp zpsSystem` = ℤ₃^×）の
**本物の双方向同型**:
- `cliTo`/`cliFrom` はいずれも `Hom`（map_mul は成分ごと `cliChar/cliAut` の map_mul ＋ funext）。
- **CLI-1 の compat 正方形 `cli_char_restr` は本物**（cast/defeq 誤魔化しなし）:
  単段 `cli_char_step`（`cli_res_char`: res の指標 = 上段指標 mod 3^m・`csaSub_zeta`＋
  `cci_indexG`）を、i≤j 一般へ差分帰納 `cli_char_restr_aux`（最上段 `ctl_restr_step` で peel＋
  IH＋`zpsT_comp` 合流）で拡張。**唯一の proof-irrelevance 吸収は proof 引数のみ**で、
  Gal 側の反復制限 `ctlRestr` と単数側の単発剰余 `zpsT` を橋渡しする実質的内容がある
  （defeq 崩壊での自明化ではない）。
- 媒介射は**担体の直接構成**（compatible family subtype に直接）で、`limit_universal`（∃ 形）

- `cli_left_inv`/`cli_right_inv` は成分ごと `cli_aut_char`/`cli_char_aut`（= cci の左右逆）＋
  funext で**証明済み**。

### 4. 射影全射性 cps が本物・choice-free か

**合格。** `cps_proj_surjective (n) (τ)` は `profPi1_proj ctlTower n`（= `limitProj … n`＝
逆極限担体の第 n 成分射・`x ↦ x.val n`、実射影であることを `ProfinitePi1.lean:128`／

`cliFrom`/`limitProj` の定義から defeq（ビルド通過が保証）。非退化は
`cps_nontrivial`（`zps_nontrivial` の定数族 2 を `cliFrom` で押し出し・`cli_right_inv`＋
`Hom.map_one` で分離）と `cps_example0`（n=0 で σ_2・char=2≠1 の実原像）で**非空虚・非自明**を
