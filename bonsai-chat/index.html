三値(1.58bit)LLM deepgrove/Bonsai 0.5B を自作WebGPUカーネルでブラウザ実行
未読込
初回はモデル本体 約1.2GB をHugging Faceからダウンロードし、ブラウザ内で三値2bit形式にパックしてキャッシュします（2回目以降は約300MBの読込のみ）。
技術メモ: なぜWebLLMではなく自作エンジンか

Bonsai は線形層の重みが三値 {-1, 0, +1}（＋出力チャネル毎のスケール）で学習された 1.58bit LLM。 WebLLM/MLC の prebuilt には三値量子化が存在せず、bf16 展開でコンパイルすると低ビットの利点（メモリ・帯域）が消える。 本ページは PrismML が llama.cpp をフォークして三値カーネルを整備したのに倣い、WebGPU の WGSL カーネルを自作して三値のまま実行する。

  • 重みは safetensors をストリーミング取得し、ブラウザ内で clamp(-1,1).round() → 2bit/重み にパック（16重み/u32）
  • 行列積カーネルは 2bit を展開しながら f32 積和 → 行スケール適用。埋め込み・lm_head・LayerNorm は f16 格納（unpack2x16float でデコード、shader-f16 拡張不要）
  • KVキャッシュも f16 パック。GPUメモリ 約400MB（三値重み 104MB + f16部 197MB + KV 100MB）
  • パック済み重みは OPFS にキャッシュされ、2回目以降はダウンロード不要
  • Bonsai は事前学習のみのベースモデル（チャット調整なし）。簡易Q&Aモードはプロンプト整形のみで実現しているため、応答品質は控えめ
