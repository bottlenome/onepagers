## 2. 中心判定 — tractable な実在第一歩はあるか

### (a) A1 体エンジン経由の実 ℚ₃(ζ₃)=ℚ₃[x]/(x²+x+1) — **BLOCKED（経路固有・三重）**

本体レベルの根拠:
1. **Field268 要求**: `simpleExtRing (K : Field268) (f : PS K.ring) …`（SimpleExtension.lean:233）、`Field268.invf : carrier → carrier`（全域 inv 函数・PolyFieldDivision.lean:60-63）。ℚ₃=q3Ring の逆元は `q3f_has_inverses` の **∃ 形＋非零 witness 付き**が忠実上限（A2c ヘッダ明記: x≠0 の否定形からの witness 抽出は Markov 原理＝choice-free 断片で関数化不能。**恒久限定**）。よって ℚ₃ は Field268 に**なれない**。これは実装不足でなく構成的数学の事実（ℚ_p は構成的に離散体でない）。
2. **ℚ ハードコード**: 一般エンジン gefNF*/GenExtTower は `PS ratRing` 上（F7 正直限定「基礎体 ℚ 固定」）。仮に Field268 問題が無くても書き直しが要る。
3. **Bezout witness も逆元依存**: `quotField_of_bezout` の Bezout 証人（∃u v, uf+va=1）は拡張ユークリッド互除法＝先頭係数の逆元反復で作る設計（M269F 正直限定）。∃ 形逆元では次数帰納の各段で witness 抽出が要り choice に触れる。

**判定: この経路は本当に閉じている。** ただし——

### (a') 整数環レベルの実 O_{L₂}=ℤ₃[ζ₃]（Gauss 対）— **実建設可能（本命・tier M）**

**ブロッカー (a) はテータ環境には無関係**である。理由: q3th/q3mr の台は体 ℚ₃ でなく群 `q3tGrp = ℤ × zpUnits 3`。μ_{3ⁿ} テータに要るのも L^× の**群提示** λ^ℤ × O_L^× であり、任意元の inv（体性）は不要——要るのは**単数の inv**（群性）だけで、それは choice-free に明示構成できる:

- **台**: `OL := z3.carrier × z3.carrier`、(a,b) ↔ a+bλ、λ=√−3（λ²=−3）。積 `(a,b)(c,d) = (ac−3bd, ad+bc)`。CRing 法則は cq3Ring（ℚ×ℚ・同一恒等式）の写経を z3 の環公理で行う（tier M・新イディオムなし）。ℤ₃[√−3]=ℤ₃[ζ₃]（2∈ℤ₃^× ゆえ）なので disc の 2 は障害でない。
- **単数群 U₂**: ノルム N(a,b) = a²+3b²。乗法性 N(xy)=N(x)N(y) は Brahmagupta 恒等式（成分計算）。`U₂ := {(a,b) // IsZpUnit 3 (N a b)}`——判定は**レベル 1 剰余**（N ≡ a² mod 3）＝既存 `IsZpUnit` と同形。**逆元は共役ノルム型の閉形式** `(a,b)⁻¹ = (a·N⁻¹, (−b)·N⁻¹)`、N⁻¹ は既存 `zpUnitInv`（Fermat＋幾何級数・M36-4）を**消費**。幾何級数の新規収束論は一切不要（2 次拡大の決定的な安さ。cq3-4 が ℚ 上で実証済みの形）。
- **L₂^× := prodGrp intGrp U₂**（付値 v_λ × 単数）——`QpUnits` と完全並行の実群提示。
- **実 ζ₃ = (−1+λ)/2**: 2⁻¹∈ℤ₃ は閉形式の整合列（レベル n 代表 (3ⁿ+1)/2）。ζ₃=(−h,h)（h=2⁻¹）で ζ₃³=1 は成分計算（(−1+λ)³=8 と 8h³=1）、ζ₃≠1・ζ₃²≠1 はレベル 1 剰余（h≡2 mod 3）の NeZeroAt witness。N(ζ₃)=4h²=(2h)²=1 ✓ 単数。**μ₃={1,ζ₃,ζ₃²} が実 U₂ の中に実在**——コードベース初の「実局所環内の実 μ₃」。
- **分岐 e=2**: 3 = −λ² ⟹ L₂^× 内で 3=(2, −1)。埋め込み `ℚ₃^×=ℤ×zpUnits ↪ L₂^×`, (j,u)↦(2j, (−1)^j·u) は単射準同型で、**v_λ∘incl = 2·v₃**（分岐指数 2 の実定理）。

**結論: 候補 (a) は「体エンジン経由なら blocked・整数環群提示なら real-buildable」**。正確な Lean スケッチは §6。既存 `eisRing 3` は同じ環の兄弟担体（Quot 提示）として実在するが、成分簿記（テータ群の交換子計算が要求する）には対提示が軽い。cnf 正直限定 (iii) の前例に従い「同型輸送は主張しない別担体」と正直申告する。

### (b) 実分岐 3 次 ℚ₃(q^{1/3})=ℚ₃[x]/(x³−q) — **建設可能だが level-3 には不要（繰延べ）**

まず精密化: level-3 テータの所属条件は qᵃw³=1、可解性は 3 | v(q)·a を要する。**q=9（v=2）のままだと** q^{1/3}=3^{2/3} が要り、ℚ₃(3^{1/3})（Eisenstein x³−3・暴分岐 e=3）さらに ζ₃ と併せて**次数 6 の暴分岐合成体**が要る。これは cofactor 逆元（Cbrt* 系イディオムが ℚ 上に実在）＋一般 Eisenstein 商の座標理論（M93F/M122 の X^{p−1}+π 特化を一般 monic Eisenstein へ一般化）で原理的には建つが、単数逆元・整域性 witness・6 成分簿記で **3〜5 モジュール級**。

**しかし q3th 自身の前例が回避法を教えている**: q3th は q=q3tQ 2=9（平方）を選んで半周期 q^{1/2}=3 を ℚ₃ 内の実元にした。全く同じトリックで **q = q3tQ 3 = 27（立方・族に既在）** を選べば q^{1/3}=3 ∈ ℚ₃ が実元になり、**追加拡大は (a') の L₂ だけで level-3 環境が完結する**:
- L₂^× 内で 27 = (−λ²)³ = λ⁶·(−1) = (6, −1)。所属 qᵃw³=1 ⟺ v_w=−2a ∧ u_w³=(−1)ᵃ——可解（a 偶: u_w∈μ₃、a 奇: u_w∈−μ₃）。所属特徴付けは **μ₆ 完全性**（u³=±1 ⟹ u∈μ₆、§2(c') 参照）で閉じる。
- E₂₇=L₂^×/27^ℤ の E[3] = {ζ₃^i·3^j}≅(ℤ/3)²（3=(2,−1)、3³=(6,−1)=q ✓）。level-3 交換子=Weil e₃ は**実 μ₃ 値**・非退化（e₃(3,ζ₃)=ζ₃^{±1}≠1・q3th_weil_g3_gm1 の同型計算）。
- **正直注記**: [EtTh] の設定は q 固定で q^{1/l} を添加する（＝(b) の 6 次体経路が完全忠実版）。q=27 選択は「同機構の実 Tate 曲線上の忠実部分ケース」であり（q=9 選択が level 2 でそうだったのと同格）、過大主張しない。6 次体経路は full-faithful 版の後続 named target として残す。

**判定: (b) は繰延べ可**。level-3 マイルストーンは (a')＋q=27 で成立。(b) が必須になるのは「q を 9 に固定した完全忠実版」または将来の一般 q。

### (c) 拡大体なしの μ₃ 値テータ群 — **本質的に不可能（toy 化の禁止）**

μ₃(ℚ₃) = {1}: x³=1 ⟹ x=1 in ℤ₃^×（x³≡x mod 3 ⟹ x≡1 mod 3、x=1+3t ⟹ x³−1=9t·(1+3t+3t²)＝単数倍 ⟹ v(x−1)=v(x³−1)−2 ⟹ 全レベルで x≡1——q3cu_mu2_complete と同じレベルシフト帰納で機械化可能）。よって ℚ₃^×-built な台の上に「μ₃ 値交換子」を持つ群を作るには μ₃ を **Bool/Fin/ℤ/ℤ³ ラベルで身代わり**するしかなく、それは AUDIT_RUBRIC の「模型」（身代わり判定）そのもの・CLAUDE.md §3（toy 主語）違反。q3thGrp を拡張する実 Quot 提示も台が ℚ₃^× 由来である限り同じ。**正直判定: (c) 単独は閉路。実 μ₃ の住処（＝(a')）が論理的前提**。

なお (c) の中の真正部分——**μ₃/μ₆ 完全性**（U₂ 内で u³=1 ⟹ u∈{1,ζ₃,ζ₃²}）——は level-3 の `mem_iff` の急所であり、成分方程式 (a+bλ)³=1 ⟺ a³−9ab²=1 ∧ 3b(a²−b²)=0 から: 3 正則 ⟹ b(a²−b²)=0; レベル 1 場合分け（a は単数・a−b と a+b の和=2a が単数ゆえ同時に 3 で割れない ⟹ 一方が単数=正則で消去）; b=0 枝は上記「ℤ₃ 内 x³=1⟹x=1」; a=±b 枝は (1±λ)³=−8 と (−2a)³=1 ⟹ u=ζ₃^{±1}。**既存イディオム（q3cu_ppow_dvd 型 Euclid・IsZpUnit witness・レベルシフト帰納）の範囲で閉じる見込み**——これが campaign の最重要 tier-L スポットであり、上のスケッチで大半は de-risk 済み。
