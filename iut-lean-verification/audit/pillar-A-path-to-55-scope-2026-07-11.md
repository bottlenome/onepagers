## 3. path (b) — 一般 n layer-kill／極限集約（downward factor の正面攻撃）

### 3.1 なぜ魅力的か

橋監査の**主 downward factor は「殺すのは第 1 層 {4,7} のみ・1+9ℤ₃（n≥3 全層）は SURVIVES」**。一般 n のパラメータ付き layer-kill 定理（第 n 層 (1+3ⁿℤ₃)/(1+3^{n+1}ℤ₃) の kill）＋極限集約（pro-3 bulk 1+3ℤ₃ の全体 kill）は、この cap を**質的に**外す唯一の言明形であり、frontier 査定は F-wild 完了時 **s_A7 0.60–0.70 ⟹ 表示 55–56** を見込む。単位仕事あたりのクレジットは (a) より確実に高い。

### 3.2 形式化可能性の敵対的査定 — **原理的には可能・現実的には campaign 級**

- **型レベルの再帰塔は書ける**: `M 0 := O_{L₂}`・`M (n+1) := (M n)³`（Z³−ζ_{3ⁿ} ねじれ畳み込み）は Lean-core の再帰型族で定義可能。σ・相対ノルム・逆元（閉形式 σx·σ²x·N⁻¹ の再帰）も帰納的に書ける**見込み**はある。
- **しかし kill に必要な閉形式部品は全て per-level の手計算恒等式として現存し、一般形は 1 つも無い**（本体読解で確認）: (i) wild 分割 3=π^{e_n}·u の単数 w の **N(w)=−1 型の一般 n 証明は未着想**（level-9 ですら設計文書の手計算検算が要った）、(ii) μ_{3ⁿ} 完全性の降下核は基底環が毎段変わり、正則性・no-cbrt・パリティ降下の**一般 n 帰納は q9cs 型スパイクの一般化＝frontier 査定の tier-L 未解決スポット**、(iii) 3ⁿ 単項式正規形・(iv) 橋の単射 3ⁿ 分岐。極限集約 (v) はさらに「全 n のテータ両立族」という新しい量化形式（両立条件の逆系）を要する。
- **frontier 査定の規模見積り（12–18 モジュール・10,000–16,000 行・3–5 ラウンド以上・tier-L スポット 3 箇所）は本査定でも妥当と判断**——むしろ「一般 n 帰納の基底ケースとして level-27 の実データが 1 つも無い」現状では下限寄りに楽観的。

### 3.3 判定

**genuine obstruction（不可能性）は無いが、5 ラウンド以内着地の確度 <30%**。表示 55 という +0.014 の閾値越えに対し、桁違いに過大な道具。**正しい位置づけは「(a) を基底ケースの 2 つ目として先に積み、そのデータで一般 n 帰納を設計する後続キャンペーン」**——(b) を今立てるのは順序が逆。**却下（本ラウンドの目的に対して）・named long-term target として保持**。
