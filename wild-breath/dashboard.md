# WILD BREATH — 野生の冒険

ゼルダの伝説 Breath of the Wild にインスパイアされた、オープンワールド2Dアクションアドベンチャー。
1ファイル完結・依存ライブラリなし（Canvas 2D + WebAudio）。

## 概要

- 種別: game
- 状態: done
- ファイル: `index.html`（1ファイル完結）
- 操作: キーボード（移動 WASD/矢印、ダッシュ Shift、攻撃 Space/J、調べる E、食べる F、武器切替 1-5/Q、マップ M）

## ゲームの流れ

始まりの祠で試練を受けパラグライダーを入手 → 祠を巡ってオーブを集めハート/がんばりを強化 →
（任意）北西の森でマスターソード入手 → 深淵の環を滑空で越え、魔王城の「厄災ガノス」を討伐。

## 櫻井メソッドの適用

- **リスクとリターン**: 王家の剣は黒ボコ2体の巣に、マスターソードはハート5の投資が前提。がんばりゲージが尽きる寸前の崖越え/滑空は落下ダメージと引き換えのショートカット
- **最初にクライマックスを**: 開始直後に宝箱→祠の試練→パラグライダー入手までを数分で体験
- **目の前に吊られたごほうび**: 画面上部に常時「次の目標」を表示。光る祠・未起動の塔・遠くに見える魔王城
- **ギュッとしてパッと解消**: 夜/雨の緊張と朝/晴れの解放、試練→オーブ→加護のサイクル
- **カービィズム**: 移動と攻撃だけで進める一方、料理・武器管理・天候読み・ファストトラベル活用で上級者は効率化できる
- **最短導線**: スタートから魔王城まで一本道の街道。E一つで祠/塔/宝箱/焚き火すべてに反応
