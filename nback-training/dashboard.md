# Nバック・トレーニング

ワーキングメモリを鍛える適応型ブレイントレーニング。鬼トレ風の音声コーチと成長記録付き。

## 概要

- 種別: game
- 状態: done
- ファイル: `index.html`（1ファイル完結・依存なし）

## モード

| モード | 内容 | 初期レベル |
|--------|------|-----------|
| 📍 位置Nバック | 3×3マスの光る位置がN回前と一致するか判定 | N=2 |
| 🔊 音Nバック | 読み上げられるかな文字がN回前と一致するか判定 | N=2 |
| 🎯 デュアルNバック | 位置と音を同時判定（Jaeggi 2008 / 鬼トレ形式） | N=2 |
| 🔢 計算Nバック | 計算を解きながらN問前の答えを入力（鬼トレ「計算お手玉」風） | N=1 |

## 仕様

- 1セッション = 20+N トライアル、一致はチャンネルごとに6回強制配置（Jaeggi プロトコル準拠）
- 適応型難易度: 全チャンネル正解率 80%以上で N+1、50%未満で N−1（下限 N=1）
- 音刺激・音声コーチは Web Speech API（ja-JP 音声を自動選択）、効果音は WebAudio 生成
- 履歴は localStorage（`nbackHistoryV1` / `nbackLevelsV1` / `nbackSettingsV1`）に保存
- 成長記録: Nレベル推移（ステップ折れ線）・正解率推移（80%基準線付き）・セッション一覧・JSON書き出し

## 機能

- [x] 位置 / 音 / デュアル / 計算 の4モード
- [x] 適応型レベル調整（80%↑でUP / 50%未満でDOWN）
- [x] 鬼トレ風 音声コーチ（開始・中間の励まし・結果講評・レベルアップ祝福）
- [x] 即時フィードバック（正答=緑 / 誤答・見逃し=赤 + 効果音）
- [x] キーボード操作（A=位置一致, L=音一致, 数字キー=計算）
- [x] 履歴管理（連続日数・今日のセッション数・自己ベストN・モード別グラフ・ツールチップ）
- [x] 設定（音声コーチ / 効果音 / 出題間隔 2.0〜3.0秒）
- [x] データ書き出し（JSON）・全削除
- [x] 遊び方と科学的背景の解説モーダル（近転移・遠転移の議論も正直に記載）
- [x] モバイル対応レイアウト（360px幅まで横スクロールなし・タッチ操作検証済み）
- [x] スマホ向け調整（ダブルタップズーム防止・タップハイライト除去・iOS AudioContext復帰・タッチ端末ではキー表記非表示）

## 設計メモ（櫻井メソッド対応）

- **リスクとリターン**: 「一致かも」で押すか迷う判断そのものがかけひき。お手つき(FA)は正解率を下げる
- **ギュッとしてパッと解消**: セッション中の緊張 → 結果画面の音声講評・レベルアップ演出で解放
- **目の前のごほうび**: 常に「80%でレベルアップ」の基準線・自己ベストN・連続日数を提示
- **カービィズム**: 位置N=2から始めて誰でも遊べ、デュアル/計算で上級者も天井なし（適応型で自動調整）
- **情報の優先順位**: プレイ中はN・進捗バー・刺激のみ。詳細は結果画面と履歴に分離
